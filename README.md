# Rhythm Game

## Platform

- Arduino Mega
- PYNQ-Z2 FPGA

## Project Components

- Game logic
- Timer
- ADC
- DAC7611P
- EEPROM
- SPI communication
- FPGA display logic

## Repository Structure

- `arduino/` - Arduino Mega source code
- `fpga/` - PYNQ-Z2 VHDL source code
- `docs/` - Project documentation
